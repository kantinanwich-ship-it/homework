GALAXY PORTFOLIO — 3 PAGE TEMPLATE
=================================
Files:
- index.html     : Landing page
- about.html     : About Me
- mywork.html    : My Work
- style.css      : Shared responsive purple galaxy theme
- script.js      : Small search interaction and footer year
- assets/reference-design.png : Uploaded visual reference

How to use:
1. Extract this ZIP.
2. Open index.html in a browser, or use VS Code Live Server.
3. Edit YOUR NAME, email/social links, descriptions, skills, and project cards.
4. Replace emoji art with your own project images as needed.

Theme follows the reference's lavender/purple palette, rounded panels, outlined borders,
dark inset information cards, floating icon navigation, and space-inspired decoration.
